# Little Lanterns — ChildrenReadingBooks

A joyful, online-first English learning experience for children. The project brings together English reading, understanding, speaking, writing and speeches with Qur'anic learning, Akhlaq, Aqa'id and Fitrat.

**Live site:** https://mahashemi.github.io/ChildrenReadingBooks/

## First prototype

The initial version is a lightweight static website designed for GitHub Pages.

- Responsive, child-friendly home page
- Interactive three-page Prophet Yusuf story prototype
- Syllables, mixed and normal reading modes
- Word explorer with syllable breakdown and vocabulary notes
- Adjustable reading size and browser read-aloud
- Qur'an corner with Surah Al-Ikhlas
- Speech stage with a gradual path towards five-minute presentations
- Akhlaq, Aqa'id and Fitrat introduction
- No child accounts, tracking or personal-data collection

## Run locally

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages when changes are pushed to `main`.

In GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions** if it is not already selected.

## Editorial principles

### Syllable annotation

Syllables are reviewed teaching annotations, not generated by splitting at vowels. The original spelling is always preserved. Each eligible multisyllabic word should be checked for pronunciation, syllable count, age-appropriate presentation and consistent handling of names and transliterations.

The reader has a QA helper available in the browser console:

```js
littleLanternsQA.storyAudit()
littleLanternsQA.inspect("A new sentence to review")
```

Any word marked `REVIEW` needs editorial attention. The current annotation dictionary is a prototype and is not yet a complete dictionary.

### Qur'anic integrity

- Keep Arabic Qur'anic text unchanged and carefully checked.
- Clearly distinguish Qur'anic text, named translations, paraphrases and child-friendly explanations.
- Cite surah and ayah references.
- Verify translation permissions and attribution before publishing full translations.
- Use trusted recitation sources and do not invent audio attribution.

### Islamic source integrity

Distinguish Qur'anic narratives, historical reports, hadith-based material and original educational stories inspired by Islamic values. Verify Shia source references and report uncertainty honestly. Do not invent dialogue or present an adaptation as a historical quotation.

### Child privacy

The initial public prototype has no accounts and stores no personal information. Any future student profiles, recording or progress features need a separate privacy and safeguarding design.

## Planned curriculum

Five progressive online learning levels, with separate digital handwriting and assessment resources. The learning pillars are reading, understanding, speaking, writing, and speech/presentation. Akhlaq, Aqa'id, Fitrat and Qur'an memorisation run throughout the curriculum.

## Current status

This is the first visual and functional prototype, not a completed or source-approved curriculum. Content, syllable annotations, Arabic typesetting, translations, audio and assessments will receive further review before release.
